# Local benchmark task

This is a harmless local-only task.

1. Read `clue_a.txt` and `clue_b.txt`.
2. Create a file named `candidate.txt`.
3. Its only line must be:

`CTFH{<clue_a>-<clue_b>}`

Replace the placeholders with the exact contents of the clue files.
Do not use the network. Do not inspect directories outside this workspace.
